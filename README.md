# Roteiros pelas Missões | Pousada das Missões

Página de ideias de roteiros (1 a 7 dias) para o link da bio do @pousadadasmissoes.
A pousada sugere; não vende pacote nem roteiro.

## Como editar

- **Textos dos roteiros:** `roteiros.js`. Cada lugar tem nome (`t`), descrição (`d`) e, quando falta confirmar, `c`.
- **Etiquetas "a confirmar":** aparecem enquanto `RASCUNHO = true` no topo de `roteiros.js`. Depois da aprovação, trocar para `false`.
- **Google:** a página está com `noindex` (rascunho). Tirar essa linha do `index.html` quando aprovar.

## Fotos

Basta colocar o arquivo com o nome certo dentro de `img/`. Ele aparece sozinho no lugar do espaço reservado.

| Arquivo | Onde aparece |
|---|---|
| `img/capa.jpg` | Capa do topo (foto horizontal, de preferência 1920 px de largura) |
| `img/cta.jpg` | Fundo do convite final |
| `img/roteiro-1-a.jpg` e `img/roteiro-1-b.jpg` | Fotos do roteiro de 1 dia |
| `img/roteiro-2-a.jpg` ... `img/roteiro-7-b.jpg` | Fotos dos roteiros de 2 a 7 dias |

No celular aparece só a foto `a` de cada roteiro.

## Link direto para um roteiro

`.../#3-dias` abre direto no roteiro de 3 dias (funciona de 1 a 7).
